Now an expensive site with a complex software architecture is available! Zhivoglas created this template from the most modern software technologies, some of which are experimental. It took a lot of time to develop and we have before you a site in which the template is the engine itself. You can do all the beauty: design, photos, colors and other things from the interface - everything is easy - yourself.

This is an example of a prompt to create a page from scratch

make a file in .mdx format for the start page of the portfolio with interactive beautiful elements in a multi-colored dark theme (but not completely black). take a photo by downloading it from the link below, the description is below, then a carousel that moves with the photo at intervals of 3 seconds (on the phone, 1 slide is visible, and on the PC, 5 are visible) and below is a section of 8 photos arranged in 2 rows (2 rows for the phone). All photos must be clickable and translated to resources on the Internet.

After that, you may need to copy some blocks and adjust them a little with the AI. And that's it! Or you can simply change the text and links in the finished file in the out folder with the .mdx extension
